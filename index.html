Case Study 02

Runtime Procedural World System

Role: Solo Developer Duration: Dissertation project Engine: UE5 Platform: PC prototype
C++ Procedural Mesh Runtime Streaming Performance Profiling

A solo university project focused on runtime terrain generation in UE5 using Procedural Mesh Components to generate and stream world chunks at runtime.

Implementation Highlights

  • Built the terrain mesh pipeline (vertices, triangles, UVs) from Perlin noise inputs.
  • Implemented chunk streaming around player position with runtime tile creation/destruction.
  • Added LOD strategies and profiler-led tuning for heavy generation moments.

Challenge → Decision → Result

  • Challenge: Support large runtime generation while keeping performance stable.
  • Decision: Combined chunked streaming with distance-based LOD and profiling iteration.
  • Result: Improved runtime stability and reduced costly mesh updates at distance.
