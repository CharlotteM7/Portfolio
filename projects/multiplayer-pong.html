Gameplay Programming · Solo · University module

Multiplayer Pong

  • Role: Solo programmer, client and server
  • Context: University module, built on the module's starter projects
  • Client: C++, SDL2 (ttf, mixer, image)
  • Server: Java, FXGL
  • Platform: Windows
Client code (C++) Server code (Java)

Overview

I took the module's basic two-player client and server and turned them into a three-player game. A third, horizontal bat guards the bottom of the screen, and a power-up spawns in the middle of the court. The server runs the simulation and sends state to the client, which renders it in SDL2 with particles, sound effects, a pause menu and a win screen.

What I added

  • Third player with a horizontal bat, and per-player scoring.
  • Power-up pickup synced from the server.
  • Client-side particles, sound effects and bat textures.
  • Pause menu with a controls screen, and a win screen.

Code and systems

The server owns the game state. The client sends input and parses state messages each frame.
