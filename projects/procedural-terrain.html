Overview

A terrain system that generates and streams the world around the player at runtime. Height comes from four layered octaves of Perlin noise, with a flat, safe spawn area that blends into the landscape. The world is split into tiles that are generated on a background thread, rebuilt at lower detail as the player moves away, and dressed with foliage that respects slope. Players can save and reload a terrain layout, and the navmesh rebuilds so AI can move across new ground.

What I built

  • Mesh generation: vertices, triangles, UVs, normals and tangents per tile.
  • Tile streaming around the player with a distance-based LOD queue.
  • Async generation so new tiles don't stall the game thread.
  • Seeded foliage scattering with slope checks, using instanced meshes.
  • Save/load of terrain settings, and runtime navmesh rebuilds.
  • Height and scale settings exposed in the editor, so the look of the world can be tuned without touching code.

Runtime terrain generation and streaming

How it's built · UE5 C++

Problem

Generate terrain around the player at runtime, far enough to feel open, without frame spikes when new ground is built.

Design

  • Height is four octaves of Perlin noise (mountains, land and two detail layers), with a flat spawn circle that lerps into the noise.
  • The world is a grid of tiles. QueuedTiles maps each grid coordinate to its mesh section and LOD level.
  • Tiles are generated in an FAsyncTask on a background thread. The LOD level divides the vertex count, so distant tiles are cheap.
  • As the player moves, RemoveLODQueue swaps outdated tiles for ones at the right detail level.
  • Foliage uses instanced static meshes, a seeded FRandomStream and slope checks, so a saved seed rebuilds the same world.

Key code

float AWorldGenerator::GetHeight(FVector2D Location)
{
    float DistFromCenter = FVector2D::Distance(Location, FVector2D(0, 0));

    if (DistFromCenter <= FlatRadius)
        return FlatHeight; // Inside the central flat area

    float ProceduralHeight = CalculateProceduralHeight(Location);

    if (DistFromCenter <= TransitionEndRadius)
    {
        // Transition zone
        float TransitionFactor = (DistFromCenter - FlatRadius) / TransitionWidth;
        return FMath::Lerp(FlatHeight, ProceduralHeight, TransitionFactor);
    }
    return ProceduralHeight;
}
